VEERAL & TINA — PURPLE WEDDING INVITATION

OPEN THE INVITATION
1. Extract this ZIP completely (do not open the HTML inside the ZIP viewer).
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Tap/click the gold seal. The envelope opens with an original magical chime
   and a soft light spread. Background music starts after the flap opens.
4. Scroll to the heart and scratch it with a finger or mouse. Once enough of
   the heart is scratched, the wedding date appears and flower petals fall.
   The “Or tap to reveal the date” button offers an accessible alternative.
5. Use the bottom-right music button to mute or resume the music.

TO SHARE WITH GUESTS
Upload index.html and the entire assets folder, keeping their relative paths,
to a static web host. Share that website link. No build command, server code,
API key, account connection, CDN or JavaScript library is required.
On phones, use a browser link to the hosted invitation: a chat attachment
preview or the phone's ZIP/Files preview may not run interactive HTML/audio.

EASY EDITS
Open index.html in a text editor.
- Bride's father: add the name between the tags with id="brideFather".
- Bride's mother: add the name between the tags with id="brideMother".
  Both spans are deliberately empty; there are no placeholder parent names.
- Wedding timing: search for “Pheras / Muhurat — To be updated”.
- If event details change, update the calendar file in assets too.
- Colours and layout: assets/invitation.css.
- Interactions and countdown: assets/invitation.js.
- Music: assets/aaj-sajeya.mp3 (the supplied song, unchanged).
- Opening sound: assets/envelope-magic.mp3 (original synthesized sound).

AUDIO AND MOTION
There is no sound before a guest taps the envelope. That tap activates audio.
Hosted pages use Web Audio to hold the song silent while the envelope opens,
then fade it in. Downloaded folders use native audio with an initial mute.
If a device or embedded browser blocks playback, the music control lets the
visitor start it manually. Device silent mode/output volume still applies.
The operating system's Reduce Motion preference shortens transitions and
replaces the falling petals with a quiet reveal.
